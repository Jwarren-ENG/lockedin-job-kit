How the estimates work

Applications × turns per application gives estimated turns. Multiply by average tokens per turn for total tokens. Review time uses your minutes per application. Weekly estimates cover the active days you selected.

One turn means one prompt and one reply. Count input, reused context and output when estimating tokens. An allowance percentage compares matching units over the same period. A model’s context window measures the size of a request. Subscription prices alone do not specify a message or token allowance.
