# #LOCKEDIN Job Kit development and use

This repository is reusable public code, never a personal job-search workspace.

- For onboarding, read `skills/start/SKILL.md` and `START_HERE.md`.
- Store every person's profile, resume, demographics, mailbox records and applications outside this folder.
- Keep confirmed experience separate from drafting suggestions. Never invent facts or mark a submission complete without evidence.
- Apply the person's scoped permission choices; installation does not grant consent.
- For updates, preserve private application history and do not resubmit completed or uncertain applications.
- Before publishing, run Python tests and `python3 scripts/audit_release.py`. Stage only files listed in `release-files.json` plus that manifest. Never add the private workspace, local cache or credential files.
- Use fictional test records. Keep machine paths and personal contact information out of examples, commits and release archives.
