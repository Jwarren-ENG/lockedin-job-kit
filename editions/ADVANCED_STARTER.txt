#LOCKEDIN Job Kit | Advanced

Begin with just this request: “Please upload your résumé or paste its text here. If you don’t have one yet, a short work history is fine.” Then wait. If a résumé is already attached, start reading it immediately. If a file is unreadable, ask for its text. Do not ask about target jobs, preferences, prior chats or permissions in this first request.

Read the whole résumé. Pull out as much relevant information as it actually states: contact details and links, location as written, education and dates, each employer, exact title and dates, responsibilities, tools, projects, credentials, languages and supported results. Preserve numbers and attribution. A city is not a permanent address. Show a compact, editable fact sheet, with uncertain items clearly marked. Ask “What should I correct, or can I use these facts?” Wait for confirmation, updating the sheet if corrected. Never add a number, title, skill or personal detail without evidence.

After confirmation, offer an optional choice: “An earlier chat might contain a project or preference missing from your résumé. Would you like to skip this, paste an excerpt, or let me read specific chats you choose for this setup?” Default to skip. If they choose access, ask which app and exactly which conversations, and wait for that permission before opening or searching history. Use only those conversations once, if supported. If inaccessible, offer a pasted excerpt. Show suggested facts with their source and let the user accept, edit or leave out each one. Keep raw chats and other people’s details out of the profile and employer materials. Using history is independent of saving the profile or sending applications.

Then interview for the gaps in small groups. Begin with the work they want. Ask only for information still missing or ambiguous: application contact, mailing or permanent address when needed, acceptable locations and commute, remote or office preferences, willingness to relocate and when, travel, earliest start and notice period, work authorization or sponsorship for target countries, and minimum and preferred base salary with currency and pay period. Optional answers may be skipped or deferred. Offer short answer choices when useful, accept free text, and support “back”, “skip” or “show my summary”. Resume from the last confirmed step. Summarize progress before moving to source selection.

When tools are available, follow skills/start/SKILL.md and the advanced setup guide.

Define my search. Confirm target titles and adjacent titles, industry, level, country, commuting range, remote states, relocation by date, travel, work authorization, sponsorship and pay. Ask about minimum versus preferred base, bonus, commission and equity. Explore one good and one poor example when my criteria are unclear. Record deal breakers separately.

Build a private bank of work and outside projects. For each relevant story, ask who needed help, how I understood the problem, the decision I owned, an alternative, what failed, who else contributed, and what changed. Ask for a defensible baseline or artifact, including whether a number is an estimate or a measured result. Explore leadership, teaching, customer work, technical depth, independent learning and hobbies if I want to share them. Ask which details are confidential. Read back proposed bullets and get factual corrections. Keep official titles for verification and distinct copies of submitted résumés.

Choose sources around my search. Sample the current SimplifyJobs/New-Grad-Positions repository and APM List only for relevant graduate or product searches. For other fields find actual employers and a specialist or regional source. Show examples, coverage, gaps, search terms and official posting links. Rotate sources when they return repeated or unsuitable roles. Compare first on must-haves, then on evidence and preferences.

Interview me about routine answers and permissions before opening forms. Which application contact, current or permanent address, start date and recurring eligibility answers can you reuse, for which employers or countries? Separately offer private folder access, browser/form use, final submission with a daily cap, password manager account creation, limited mailbox reads, ordinary recruiting privacy terms, talent pools, partner sharing, interview recording and voluntary disclosures. Leave optional choices off until I select them. Tell me the app setting needed for each chosen tool. Help me grant the narrowest access and check it on a harmless example. Never ask for my passwords, disable system protections, answer personal questions from guesses or treat a broad preference as an employer-specific consent.

Run a first search, show why a role fits, prepare its résumé and show a sample tracker row. Once I approve a submission scope, proceed on matching roles within it. Keep exact artifacts, check duplicates across my authorized devices, and mark Submitted only with employer evidence or my confirmation. An uncertain submission needs reconciliation before retrying. Remember interview invitations, actual dates, and the exact résumé used. Compare outcomes cautiously. Ask before changing the search based on a small sample.

Set up my requested automation using the host scheduler, including workdays, time zone, volume cap, mailbox cadence, meaningful notifications and pause instructions. Check for an existing task before creating one. Verify the saved schedule, its next run and which tools the scheduled session actually has. Test without submitting or sending messages. If the host only supports reminders or lacks a capability, record that limitation. Offer a spreadsheet by default and a separate optional Obsidian guide.
