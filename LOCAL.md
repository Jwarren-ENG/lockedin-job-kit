# Use #LOCKEDIN Job Kit with a local model

Use this edition when you want your résumé and application drafts to stay on your computer. The Local download contains a starter, this guide and the optional dashboard guide. One short chat and a text file are enough.

1. Open a local chat app you already use. With **LM Studio**, download a model that fits your computer before working offline, load it, then open a chat. With **Ollama**, select a locally downloaded model. In a terminal you can use `ollama list` to see installed models and `ollama run MODEL` with a name from that list. Use a local model and keep cloud providers and external tools off if you want offline processing. [LM Studio offline guide](https://lmstudio.ai/docs/app/offline) · [Ollama guide](https://docs.ollama.com/quickstart)
2. Open **LOCAL_STARTER.txt** in your download, copy its contents and paste them into the chat. [Read the starter on GitHub](editions/LOCAL_STARTER.txt). Provide your résumé first. Check the facts the model extracted and correct them before it asks for missing details such as target roles, relocation and salary. You can skip past chats or paste a short excerpt for review. Offline chat usually has access only to the text you supply. If file attachments are unavailable, copy the text of your résumé.
3. Have the model suggest where to search. In your normal browser, open a relevant employer posting yourself. Paste the job text, link and date into the chat. The human browser step uses the internet. The model can compare your background with the pasted text offline.
4. Compare every title, number and result in the draft with your confirmed facts before saving it. Smaller models sometimes repeat an onboarding question or add a plausible detail. Correct the draft and keep only what you can support. Save the edits and tracker row to a private folder. Submit through the employer site yourself, then record the receipt. For the next session, paste the compact summary and the next posting. This works with a short context window and a model that has no memory.

**Scheduling.** A local model only runs when its host runs it. For a simple reminder, use your calendar and include “Open my job search folder, check my saved sources and review one posting.” If you already have a local agent with a scheduler, follow the [Advanced guide](ADVANCED.md#schedule-your-search), test it with fictional data and grant each tool separately. A local chat does not acquire browser or email access by downloading this kit.

Want a tracker your assistant can update on disk? The [Advanced download](https://github.com/Jwarren-ENG/lockedin-job-kit/releases/latest/download/lockedin-advanced.zip) includes optional Python tracking tools. You can use the Local starter with those tools. Obsidian is a separate choice.
